# Portfolio landing page

The page opens with Aldrin’s value proposition and leads into a filterable gallery of seven projects. KATHA has a dedicated tabletop feature. Earlier projects and career details remain available in expandable sections.

Edit featured projects in `src/featured.ts` and earlier projects in `src/projects.ts`. Project screenshots live in `public/projects/`. Amari’s Photobooth and KATHA use typographic covers. The contact section includes a CV request by email.

Run `npm ci` to install dependencies, `npm run dev` for development, and `npm run build` to type-check and build for production.
